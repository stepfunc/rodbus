This guide is the primary documentation for Step Function I/O's Modbus [library](https://github.com/stepfunc/rodbus). Here you'll find:

* Which parts of Modbus the library implements
* How to use the library's Application Programming Interface (API)
* How the API maps to Modbus concepts
* How to get pre-built binary distributions of the library for supported languages
* [Example programs](../examples/summary.mdx) in each language to run first

## Modbus standard

This guide covers many Modbus concepts but is not a replacement for the standard. If you plan to develop a product that uses Modbus,
you can get a free copy from the [Modbus Organization website](https://modbus.org/).
