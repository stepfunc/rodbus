Creating a TLS server is the same process as creating a [TCP server](./tcp_server.mdx),
except that an extra `TlsServerConfig` is required. For more details about TLS support and the configuration options,
check the [TLS general information](../tls.mdx) page.

There are two kinds of TLS server:

* `create_tls_with_authz` (`spawn_tls_server_task_with_authz` in Rust) implements Modbus Security: each client certificate
  must carry a role, and your [`AuthorizationHandler`](../tls.mdx#modbus-security) decides which requests that role may make.
* `create_tls` (`spawn_tls_server_task` in Rust) takes no `AuthorizationHandler`, doesn't require the role, and lets any
  authenticated client perform any Modbus operation.
